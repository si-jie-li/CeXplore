# C. elegans Lineage Explorer Lite：用户使用指南

本文面向不熟悉软件开发的使用者。你不需要修改代码，也不需要理解 React、JavaScript 或 Three.js。只要按顺序复制少量终端命令，就可以在本机浏览器中使用工具。

---

## 1. 这个工具能做什么

它用于查看一个或多个 *C. elegans* 胚胎的细胞核三维坐标和细胞谱系，并让不同界面彼此联动。

主要用途：

- 像视频一样播放不同时间/帧的细胞核位置；
- 在三维空间中旋转、缩放和平移胚胎；
- 同时导入多个文件、勾选多个 embryo，并选择单独显示、叠加或逐细胞平均位置；
- 使用 Color by embryo 区分叠加的不同胚胎；
- 从谱系树选择一个细胞，或选择它在数据中出现的全部后代；
- 从细胞列表搜索和多选细胞；
- 给 ABpl、MS、C 等谱系群体分配不同颜色；
- 保存多个 Cell Group，并独立显示、隐藏、改名和改色；
- 只显示感兴趣的群体，或保留其他细胞作为淡色空间背景；
- 查看所选细胞的近期运动轨迹；
- 查看细胞坐标、parent、祖先和后代数量；
- 导出一个很小的 Session JSON，保存颜色、分组和显示设置。

当前版本不做定量统计，不显示细胞膜或显微图像。多胚胎平均要求输入坐标已经在同一个 AP/LR/VD 系统中对齐。

## 2. 数据是否会上传

不会。工具在你自己的电脑上运行：

```text
本地数据文件 → 本地浏览器内存 → 本地可视化
```

当前代码中没有上传服务器、数据库或云端保存功能。关闭或刷新页面后，尚未导出的临时选择和分组会消失，但原始数据文件不会被修改。

## 3. 第一次打开工具

以下步骤适用于当前这台 Mac。

### 第 1 步：打开 Terminal

1. 按 `Command + 空格`；
2. 输入 `Terminal`；
3. 按回车打开终端。

终端是一个文字命令窗口。下面的命令可以逐行复制，每行复制后按一次回车。

### 第 2 步：进入项目文件夹

复制：

```bash
cd "/Users/cindy_li/Desktop/CeXplore"
```

这条命令只是在终端中进入该文件夹，不会改变任何数据。

### 第 3 步：启用已经安装的 Node.js

复制：

```bash
source ~/.nvm/nvm.sh
```

然后复制：

```bash
nvm use
```

如果成功，会看到类似：

```text
Now using node v22.14.0
```

这里的 Node.js 只是启动本地网页所需的运行环境。它不会分析生物数据。

### 第 4 步：安装依赖（通常只需第一次执行）

复制：

```bash
npm install
```

当前项目已经安装过依赖。如果 `node_modules` 仍在，这一步通常很快。以下情况需要重新执行：

- 把项目复制到另一台电脑；
- 删除过 `node_modules`；
- `package.json` 的依赖发生变化。

安装过程可能显示 `packages are looking for funding`，它只是开源项目提示，不影响使用。

### 第 5 步：启动工具

复制：

```bash
npm run dev
```

成功后终端会显示类似：

```text
VITE ready
Local: http://127.0.0.1:5173/
```

不要关闭这个终端窗口。终端中的程序相当于本地网页服务，关掉后浏览器页面就不能继续加载。

### 第 6 步：在浏览器打开

在 Chrome、Safari 或 Edge 地址栏输入：

```text
http://127.0.0.1:5173/
```

然后按回车。

如果终端显示的端口不是 `5173`，例如 `5174`，请打开终端实际显示的地址。

## 5. 如何正确关闭

使用结束后：

1. 如果需要保留分组和颜色，先导出 Session；
2. 回到启动工具的 Terminal；
3. 同时按 `Control + C`；

## 8. 导入真实研究数据

此前用于测试的文件位于：

```text
/Users/cindy_li/Desktop/C.elegans/spatial/data/01_wt_truncated_axis_aligned.tsv
```

如果你之后移动了该 TSV，请在文件选择窗口使用它的新位置；工具不要求真实数据存放在项目目录中。

它含多个 embryo。映射 `embryo_id` 后，程序会列出其中所有非空 ID，你可以勾选一个或多个。

### 第 1 步：选择文件

在首页点击：

```text
Choose dataset files
```

如果已经在主界面，点击顶部：

```text
Open datasets
```

在文件选择窗口进入：

```text
Desktop → C.elegans → spatial → data
```

选择一个文件；也可以按住 `Command`（macOS）或 `Control`（Windows/Linux）在文件窗口中一次选择多个文件：

```text
01_wt_truncated_axis_aligned.tsv
```

### 第 2 步：检查坐标映射

在 Column Mapper 中设置：

| 界面项目 | 应选择的列 | 原因 |
|---|---|---|
| Cell ID / name | `cell_name` | 细胞名称 |
| AP coordinate | `A_pos` | anterior–posterior 轴 |
| LR coordinate | `L_pos` | left–right 轴 |
| VD coordinate | `D_pos` | ventral–dorsal 轴 |

不要选择原始 `X/Y/Z`，因为当前需求指定使用校正后的 `A_pos/L_pos/D_pos`。

导入窗口、三维坐标轴和 Cell info 都会显示 AP/LR/VD。工具不会根据数字自动翻转方向，所以请确保所选列本身就是你希望展示的生物学方向和正负定义。

### 第 3 步：选择播放坐标

选择：

```text
Time
```

Time column 选择：

```text
time
```

该文件中的 time 是离散时间/帧号，也是谱系树纵轴使用的坐标。

Parent cell 可保持：

```text
Not mapped
```

因为程序会使用 canonical lineage table 自动解析。

### 第 4 步：扫描并选择 embryo

设置：

```text
Embryo / sample column → embryo_id
```

选择该列后，程序会扫描完整文件，并在 **Embryo IDs to import** 中列出 `ctr_emb1`、`ctr_emb2` 等值。勾选想导入的 embryo；可用 `All` 全选或 `None` 清空。至少要勾选一个。

如果一次选了多个文件，每个文件会依次出现自己的 Column Mapper。顶部会显示 `file 1 of N`。完成当前文件后点击 `Load & continue`，最后一个文件点击 `Load selected`。不同文件可以使用不同列名，但必须选择相同的播放模式（都用 Time、都用 Frame，或都用 Static）。

### 第 5 步：开始加载

点击：

```text
Load selected
```

底部会显示：

```text
xxx rows scanned · xxx retained
```

这是正常现象。对于带 embryo column 的大文本文件，程序会扫描一次取得 ID 列表，确认后再次流式扫描，并只把勾选的 embryo 留在内存中。扫描期间不要关闭对话框或浏览器页面。

`ctr_emb1` 的预期结果：

```text
20,926 observations
722 cells
185 time points
最多 362 nuclei/frame
0 unresolved cells
```

顶部数据摘要应显示文件名、`ctr_emb1`、细胞数和 time points。

## 9. 支持什么输入格式

### CSV

逗号分隔，例如：

```csv
cell_name,frame,AP,LR,VD
AB,1,10.2,15.1,8.0
ABa,2,9.8,14.7,8.4
ABp,2,10.8,15.5,7.8
```

### TSV

Tab 分隔。给定的真实数据就是 TSV。对于大文件，TSV/CSV 是推荐格式。

### XLS/XLSX

支持 Excel 工作簿。如果有多个 worksheet，Column Mapper 顶部会出现 Worksheet 选择。

Excel 文件会整体读取到内存。非常大的 Excel 文件建议先转为 TSV。例如在 Python 中：

```python
import pandas as pd

df = pd.read_excel("input.xlsx", sheet_name="Sheet1")
df.to_csv("input.tsv", sep="\t", index=False)
```

## 10. 必需列和可选列

### 必需

- Cell ID / cell name；
- AP；
- LR；
- VD。

坐标必须可以转换为数字。

### 可选

- Time；
- Frame；
- Parent cell；
- Embryo/sample ID。

### Time 和 Frame 同时存在

在 Column Mapper 中选择哪个控制播放：

- 选 **Time**：时间轴和谱系纵轴使用 time；
- 选 **Frame**：使用 frame；
- 选 **Static / canonical time**：忽略时间列，把所有有效记录放在一个静态状态；谱系树改用内置 canonical developmental time（分钟）。

如果同一个细胞在静态模式下有多行，它们会成为同一 step 的重复项，最终只保留最后一条。因此有多时间点的数据不要误选 Static。

### Parent cell

输入 parent 列会覆盖或补充 canonical lineage。适用于：

- 自定义细胞名称；
- 非标准 tracking ID；
- canonical table 中没有的关系。

如果 parent 缺失且 canonical table 也不认识该名称，细胞仍会显示，但标记为 lineage unresolved。

## 11. 如何控制时间播放

播放控件位于右下区域顶部。

### 按钮

- `▶`：播放；
- `Ⅱ`：暂停；
- 左侧跳转按钮：上一帧；
- 右侧跳转按钮：下一帧。

到达最后一个时间点后，再前进会回到第一个时间点。上一帧在开头也会循环到末尾。

### 时间轴

拖动 slider 会立即显示对应 time/frame。右下文字显示：

```text
Time 85
85 / 185
```

第一项是数据中的实际 time 值，第二项是当前时间点在排序列表中的位置。

### 播放速度

可选：

```text
0.25×  0.5×  1×  2×  4×
```

速度改变的是每个数据时间点停留多久，不改变源数据时间，也不在相邻帧之间插值。

### 母细胞和子细胞

当前帧只显示该 step 中存在的记录。母细胞何时消失、daughter 何时出现完全由输入数据决定。

## 12. 如何操作三维胚胎

把鼠标放在右上 3D embryo 区域。

### 旋转

按住鼠标左键拖动。

### 缩放

滚动鼠标滚轮，或在触控板上双指上下滑动。

### 平移

按住鼠标右键拖动。Mac 触控板需要使用已启用的右键手势。

### Reset

点击三维视图右上角：

```text
Reset
```

相机回到默认角度。

播放、暂停、上一帧、下一帧、拖动时间轴或切换显示 embryo 都不会自动 Reset。你手动旋转、缩放或平移后的视角会一直保留，直到主动点击 Reset 或 Focus。

### Focus

1. 先选择一个或多个当前帧存在的细胞；
2. 点击 `Focus`；
3. 相机中心移到这些细胞的平均位置。

如果所选细胞在当前帧都不存在，Focus 不会移动。先把时间轴移动到该细胞存在的时间。

### 点击细胞核

点击一个球：

- 它成为当前 selection；
- 谱系树对应节点高亮；
- Cells 列表对应 checkbox 选中；
- Cell info 显示它的信息。

点击三维背景会清空 selection。

### 选择显示哪些 embryo

点击三维视图右上角的 `Embryos 已显示数/总数`，打开独立的 Embryos 框：

- 勾选任意一个或多个 embryo：只显示这些 embryo；
- `All`：显示所有已导入 embryo；
- `Overlay`：每个 embryo 的 nucleus 都作为独立球显示；
- `Mean position`：对当前勾选 embryo 中同一 time/frame、同一 cell 的可用坐标求算术平均，只画一个球；
- `Color by embryo`：Overlay 时按 embryo 分配颜色，颜色圆点和 embryo 列表一致。

Mean position 不要求每个 embryo 在该时间都有该 cell：只对实际存在该 observation 的勾选 embryo 求平均。该功能假定输入胚胎已经完成坐标注册；工具本身不会旋转、平移或缩放不同 embryo 来做 registration。

## 13. 如何使用谱系树

谱系树位于左上。

树中的竖线代表一个细胞从出生到分裂或最后观测时刻的生命段；横线代表母细胞分裂并连接 daughters。纵轴时间向下增加，使用你选择的 Time/Frame；没有时间列时使用 canonical developmental minutes。

### 放大、缩小和平移

- 滚轮：缩放；
- 按住左键拖动空白处：平移；
- 前 6 个谱系层级会一直显示细胞名；更晚的名字把鼠标悬停在 branch 上才显示。

### Cell 模式

树顶部选择：

```text
Cell
```

然后点击某个 represented cell 的竖直 branch，只选择这个细胞。较粗的透明点击区覆盖细线，所以不需要非常精确地瞄准。

### Lineage 模式

树顶部选择：

```text
Lineage
```

点击 ABpl 的 branch 会选择：

- ABpl 本身；
- canonical tree 中位于它下方；
- 并且实际出现在当前上传数据中的所有后代。

连接树结构但不在上传数据中的祖先不会加入 selection。

### 快捷操作

无论当前是 Cell 还是 Lineage 模式，按住 `Shift` 再点击一个 branch，都会按 Lineage 方式选择后代。点击一个只用于连接结构、但输入数据中没有坐标的祖先 branch，也会自动选择它在上传数据中 represented 的后代。

要一次选择多个不相邻对象：

- macOS：按住 `Command` 点击多个 branch；
- Windows/Linux：按住 `Control` 点击多个 branch；
- Cell 模式会逐个增加或取消 cell；
- Lineage 模式会整组增加或取消 represented descendants。

给 selection 选择颜色后，无论 selection 来自 tree 还是 Cells list，对应 cell 的 lineage branch、列表圆点和三维 nucleus 都会立即使用同一颜色。

### 时间状态

如果有 time/frame：

- current cell：正常或较亮；
- past cell：稍淡；
- future cell：更淡并可能使用虚线；
- 横向红色虚线：当前时间位置。

谱系结构始终保留，不会因为细胞当前不存在而整段消失。

### Unresolved

名称后出现 `?` 或底部出现 unresolved badge，表示程序不知道它的 canonical parent。它仍会显示在三维视图和 Cells 列表中。

## 14. 如何使用 Cells 列表

点击左下的：

```text
Cells
```

### 搜索

在 Search cells 中输入：

```text
ABpl
```

列表会显示名称中包含 ABpl 的细胞。搜索不改变 selection，只过滤列表显示。

- 点击 checkbox 选择；
- 再次点击取消；
- 可以勾选多个不同细胞；
- 当前选择数量显示在颜色区上方。

### 从列表选择 lineage

### Clear

点击颜色区域右上方的 `Clear`，清空 selection。已经保存的 group 和颜色不会因此删除。

## 15. 如何给细胞着色

### 基本流程

1. 从谱系树、三维视图或 Cells 列表选择细胞；
2. 检查 `N selected` 数量；
3. 点击下方 12 个颜色之一；
4. 三维细胞核、树和列表颜色立即同步。

也可以点击颜色行末尾的 `+` 打开自定义颜色选择器。

### 是否保存为 group

默认勾选：

```text
Save colored selection as a group
```

着色后会自动建立一个可管理的 Cell Group。

如果不想保存 group，可以先取消勾选，再点击颜色。颜色仍会分配，但没有 group 的 show/hide/rename 控件。

### 推荐做法

对需要长期比较的群体始终保留这个勾选。例如：

```text
选择 ABpl lineage → 蓝色
选择 ABpr lineage → 橙色
选择 MS lineage   → 绿色
```

然后播放时间，观察它们的空间关系。

不要反复给同一个 selection 点击不同颜色来“试色”，因为默认会建立多个重叠 group。已经建立 group 后，请到 Cell groups 中直接修改颜色。

## 16. 如何管理 Cell Groups

点击左下：

```text
Cell groups
```

每个 group 显示：

- 颜色块；
- group 名称；
- 细胞数量；
- 来源，例如 lineage from ABpl；
- 一组操作图标。

### 改名

1. 点击 group 名称文字；
2. 删除原名；
3. 输入新名，例如 `ABpl descendants`；
4. 点击其他位置完成。

### 改颜色

点击最左侧颜色块，在系统颜色选择器中选择新颜色。该 group 的树、列表、轨迹和三维颜色会同步更新。

### 显示/隐藏

点击眼睛图标：

- 开眼睛：visible；
- 关闭眼睛：hidden。

隐藏会立即从三维显示中去掉该 group 的细胞。如果同一个细胞同时属于另一个可见 group，它仍可能显示。

### Select all cells

点击鼠标指针图标，把 group 中所有显式 cell IDs 放入当前 selection。之后可以显示轨迹或在树/列表中查看它们。

### Focus group

点击 Focus 图标：

1. 先选择 group 的全部细胞；
2. 再把相机中心移动到当前帧实际存在的 group cells。

### 删除

点击垃圾桶图标删除 group。源数据不会删除。

## 17. 三种 Display 模式

右下 Display 区域有三种模式。

### Color groups

适合总体观察：

- 所有细胞保持可见；
- groups 使用指定颜色；
- 其他细胞为中性灰色。

### Highlight

默认且最推荐：

- groups 和当前 selection 明亮、不透明；
- 其他细胞强烈淡化但仍保留；
- 适合观察目标群体在整个胚胎中的空间环境。

可以用 Background opacity 调整背景细胞透明度。

### Isolate

适合只看目标群体：

- 只显示 visible groups；
- 多个可见 group 会同时显示；
- 通过 Cell groups 的眼睛图标决定哪些 group 参与显示。

如果还没有任何 group，Isolate 会显示当前 selection。

### 多 group 比较

例如已有：

```text
ABpl = blue
ABpr = orange
MS   = green
```

三个 group 都保持 visible，在任何模式中都可同时比较。切换到 Isolate 可只看这些群体，切换到 Highlight 可把其他细胞作为淡色背景。

---

## 18. 调整细胞核和背景

### Nucleus size

拖动滑块调整球大小。它只改变显示，不改变坐标或数据。

建议：

- 细胞少的早期帧：可适当增大；
- 细胞多的晚期帧：适当减小，减少遮挡。
- 多胚胎叠加时可把它调到新的最小值 `0.05`，尽量减少细胞核互相遮挡。

如果开启 `Color by embryo`，三维视图会暂时优先使用各 embryo 的颜色，便于区分重叠数据；谱系树和细胞列表仍保留你给细胞或 group 指定的颜色。关闭该选项后，三维视图立即恢复细胞/group 颜色。

### Background opacity

只影响淡化的非目标细胞。数值较小，目标群体更突出；数值较大，更容易理解整体胚胎结构。

它不会改变 group cells 的不透明度。

## 19. 如何显示轨迹

轨迹只针对当前 selection。

### 操作

1. 选择一个或多个细胞，或在 Cell groups 中点击 Select；
2. 点击右下 `Trails`；
3. 选择历史长度：

```text
5 frames
10 frames
25 frames
All previous
```

4. 播放或拖动时间轴。

轨迹颜色继承细胞/group 颜色。

### 注意

- 没有 selection 时 Trails 按钮不可用；
- 只画该细胞实际存在的历史位置；
- 不自动画所有细胞，以免画面过度拥挤；
- 不在缺失帧之间生成生物插值；
- 不把 mother 和 daughter 强行连成一条轨迹。

如果画面太乱，缩短到 5 或 10 frames，或减少 selection。

## 20. Labels 和 Axes

### Labels

点击 `Labels` 显示细胞名。

为了保持性能：

- 当前帧不超过 160 个细胞时，可以显示全部当前标签；
- 超过 160 个时，只显示 selection 的标签。

### Axes

点击 `Axes` 显示或隐藏 AP/LR/VD 坐标轴。

这些标签对应导入时的三项列映射。工具不会自动注册胚胎方向或翻转正负号；输入列的含义由用户负责确认。

## 22. 如何保存和恢复工作

浏览器刷新会丢失当前内存状态，因此重要分析应导出 Session。

### 导出 Session

1. 完成着色、命名和显示设置；
2. 点击顶部 `Session`；
3. 浏览器下载类似：

```text
01_wt_truncated_axis_aligned.lineage-session.json
```

它包含：

- column mapping；
- cell colors；
- groups 和显式 cell IDs；
- group 名称、颜色、visible 状态；
- display settings。

它不包含原始 233 万行数据。

### 恢复 Session

顺序非常重要：

1. 先重新打开原始 CSV/TSV/XLSX；
2. 使用与之前相同的 embryo ID；
3. 等数据加载完成；
4. 点击顶部 `Import`；
5. 选择之前的 `.json`；
6. 出现 `Session imported` 后检查 groups。

如果先导入 Session、没有先加载数据，程序会提示先加载 source dataset。

如果文件名不同，也会警告配置来自另一个数据文件。程序会自动删除 Session 中在当前数据集不存在的 cell IDs。

## 23. 一个推荐的实际探索流程

下面是从头到尾的建议工作流。

### 目标

比较 ABpl、ABpr 和 MS 后代在发育中的空间组织。

### 操作

1. 导入 `01_wt_truncated_axis_aligned.tsv`；
2. 映射 `cell_name / A_pos / L_pos / D_pos / time`；
3. 选择 `embryo_id = ctr_emb1`；
4. 在 Lineage tree 顶部选择 `Lineage`；
5. 搜索或在树中找到 `ABpl`；
6. 点击 ABpl，确认 selection 数量；
7. 选择蓝色，保持 Save as group；
8. 找到 `ABpr`，选择 lineage；
9. 选择橙色；
10. 找到 `MS`，选择 lineage；
11. 选择绿色；
12. 打开 Cell groups，把名字改为：

```text
ABpl descendants
ABpr descendants
MS descendants
```

13. 切换到 Highlight；
14. Background opacity 调到较低；
15. 从早期开始播放；
16. 观察三个群体是否保持凝聚、分离、接触或汇聚；
17. 暂停到感兴趣时间；
18. 在 group 中 Select ABpl，再打开 10-frame Trails；
19. 用 Focus 定位；
20. 切换 Isolate 检查群体内部结构；
21. 导出 Session 保存结果。

## 24. 常见问题和解决办法

### Terminal 显示 `command not found: nvm`

先执行：

```bash
source ~/.nvm/nvm.sh
```

然后再执行：

```bash
nvm use
```

### 显示 `command not found: node` 或 `npm`

同样先执行：

```bash
source ~/.nvm/nvm.sh
nvm use
```

再用下面命令检查：

```bash
node --version
npm --version
```

### `npm run dev` 后浏览器打不开

检查：

1. Terminal 是否仍在运行；
2. 是否使用 Terminal 显示的完整 Local 地址；
3. 地址是否误写成 `https`，正确的是 `http`；
4. 如果 5173 被占用，Vite 可能显示 5174 或其他端口。

### 页面显示，但三维区域空白

依次检查：

1. 当前帧是否有 nuclei；
2. 是否启用了 Isolate，但所有 groups 都被隐藏；
3. 点击 Reset；
4. 切回 Color groups；
5. 更新 Chrome/Safari/Edge，确认浏览器支持 WebGL。

### 导入后提示没有有效 observations

最常见原因：

- Cell ID/AP/LR/VD 映射错；
- 把含多时间点的数据误选为 Static；
- Time/Frame 列包含非数字；
- Embryo ID 拼写错误；
- 选择了错误 worksheet；
- 坐标列为空。

重新点击 Open datasets 并检查映射及勾选的 embryo ID。

### 加载真实 TSV 较慢

文件有约 233 万行时，浏览器需要先扫描全文件才能列出 embryo ID。只勾选实际需要导入的 ID，避免把不需要的数据留在内存中；等待底部 scanned/retained 数字更新。

不要同时打开多个该文件的导入任务。

### 某些细胞显示 unresolved

这表示：

- 名字不在 canonical table；并且
- 输入没有为它提供 parent。

它的三维位置仍然有效。若需要把它接入谱系，可在输入表增加 parent 列并在 Column Mapper 映射。

### 选择 lineage 后数量与预想不同

程序只选择上传数据中 represented 的后代，不会把 canonical table 中存在但坐标文件中完全没有的细胞加入 selection。

### Focus 没有反应

所选 group 可能在当前帧没有任何细胞。拖动时间轴到这些细胞实际存在的时段，再点击 Focus。

### 刷新后 groups 消失

当前版本不使用数据库或浏览器长期存储。刷新前必须点击 Session 导出 JSON。

## 25. 哪些操作不会改变原始数据

以下操作都只改变显示或浏览器内存：

- 旋转、缩放、平移；
- 播放、暂停和拖动时间轴；
- 选择细胞；
- 着色；
- 建立、改名、隐藏或删除 group；
- 调整 nucleus size 和 opacity；
- 显示轨迹、标签和坐标轴；
- Focus/Reset camera；
- 导出 Session。

工具不会写回原 CSV/TSV/XLSX。

## 26. 当前限制

- 可以叠加或求平均，但工具不会自动完成多胚胎空间注册、轴翻转、尺度校正或时间配准；输入必须已经处于可比较的 AP/LR/VD 与时间坐标中；
- 平均位置只计算当前所选胚胎、当前时间点实际存在该细胞的坐标；当前版本不计算方差、置信区间或个体差异；
- AP/LR/VD 依赖用户正确映射输入列，工具不会自动注册方向或翻转坐标；
- 没有细胞表面或显微图像；
- 没有位置插值；
- 没有 cohesion、purity、distance 等定量指标；
- 没有编辑 canonical lineage 的界面；
- Session 不保存原始数据；
- 超大 XLSX 会占用较多内存；
- 一个细胞属于多个 group 时，最近建立的可见 group 颜色优先。

这些限制不会影响当前核心目的：快速选择任意谱系/细胞群，在真实时间点的三维核坐标中持续追踪其空间组织。
