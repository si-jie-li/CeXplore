# CeXplore 群体空间指标：方法与解释

本文记录第一阶段定量模块的准确计算方法。它的目标是把 3D 观察转成容易比较的描述量，帮助判断一个 lineage/group 是否保持邻域纯度、连通、紧凑或形成方向性结构。它不是机制因果检验，也不应把一个高分直接解释为某种 cell fate 原因。

## 1. 什么时候计算

CeXplore 加载数据、播放 3D 或选择细胞时不计算这些指标。只有用户展开 **Group analysis**、选好 group、displayed embryos、metrics 和参数后点击 **Run analysis**，程序才启动一次分析。

计算在 Web Worker 中运行。主线程继续负责 lineage tree、Three.js 和鼠标交互。改变选择或参数不会自动重算，避免大数据上产生不可见的重复工作。

## 2. 计算单位

最小计算单位是：

```text
一个 embryo × 一个真实 time/frame
```

每个单位只包含该胚胎该时间真实存在的 nuclei。不同胚胎永远不会先叠到一起建图；Mean position 也不用于指标。跨胚胎中位数和 IQR 只在每个胚胎已经独立得到结果之后计算。

因此输出表每行对应一个 `embryo_id × time/frame`。

## 3. Lineage-aware 动态成员

Saved group 始终保存 explicit cell IDs，保证选择可复现。分析时再根据 group 来源决定当前成员：

- `lineage`：从 `rootCell` 沿 canonical/supplied parent graph 找所有 represented descendants，再与当前 frame 实际存在的 cell IDs 求交集；
- `manual` 或 `cell`：只与保存的 explicit IDs 求交集，不自动加入女儿；
- 从 saved group 重新选择时保留它原来的 lineage/manual 来源。

例如 ABpl lineage：

```text
ABpl 尚未出现：group size = 0
ABpl 存在：{ABpl}
ABpl 消失、ABpla/ABplp 出现：{ABpla, ABplp}
更晚：使用当时实际存在的 represented descendants
```

这避免把已经分裂消失的 mother 与 daughters 同时当成当前细胞。

## 4. Symmetric kNN graph

对当前 embryo/time 的全部 nuclei，以原始 AP/LR/VD 坐标计算欧氏距离。每个 nucleus 指向最近的 k 个邻居；如果 `i` 选择 `j` 或 `j` 选择 `i`，最终无向图中保留一条 `i—j` 边。

```text
E = union(i → k nearest neighbors)
```

默认 `k=6`。k 小时描述非常局部的邻域；k 大时图更容易连通，也更平滑。不同 group 的比较应使用同一个 k，并用几个相邻 k 做 sensitivity check。

## 5. 四项指标

### 5.1 Neighborhood purity

令：

- `E_in`：两个端点都属于 group 的边数；
- `E_boundary`：只有一个端点属于 group 的边数。

```text
Purity = 2 E_in / (2 E_in + E_boundary)
```

范围 0–1。它等价于“所有与 group 相连的 edge ends 中，有多少另一端仍在 group 内”。高值表示局部邻域中 group 与外部细胞接触较少。

### 5.2 Largest connected component fraction（LCC）

只保留 group cells 及 group-group edges，得到 induced subgraph。设最大连通分量含 `n_LCC` 个细胞，当前 group 有 `n_group` 个细胞：

```text
LCC = n_LCC / n_group
```

范围 0–1。高值说明大多数 group cells 在当前 k 尺度下属于同一个连接块。它不等于组织有真实物理接触，因为输入只有 nucleus positions。

### 5.3 Normalized radius of gyration

先求 group centroid `c`：

```text
Rg = sqrt(mean_i ||x_i - c||²)
```

再除以同一 embryo/time 全部 nuclei 的 AP range：

```text
Normalized Rg = Rg / (max(AP) - min(AP))
```

较低表示 group 相对整个胚胎 AP 长度更紧凑。使用统一缩放或平移所有三轴不会改变该值；如果胚胎尚未注册、轴尺度含义不同，跨胚胎解释仍会受影响。

### 5.4 Shape anisotropy

对 group 的 AP/LR/VD 坐标计算 3×3 covariance matrix，得到从大到小的特征值：

```text
λ1 ≥ λ2 ≥ λ3 ≥ 0
Anisotropy = (λ1 - λ3) / λ1
```

范围约 0–1：

- 接近 0：三个主轴的总体扩展相近；
- 接近 1：至少一个方向的扩展远大于最小方向，可来自细长或扁平结构。

仅靠这一标量不能区分“线状”与“片状”，所以 CSV 同时输出 `λ1/λ2/λ3`，以后可以派生 elongation 和 flatness。

## 6. Local size-matched random-group null

每个 embryo/time 独立建立 null：

1. 保持随机 group size 与真实 group 完全相同；
2. 计算真实 group centroid；
3. 按经过各轴 span 标准化后的 centroid distance 排序全部 nuclei；
4. 取最近的局部候选池，大小为 `min(total, max(4n, n+8, 24))`；
5. 从候选池无放回随机抽取 n 个细胞；
6. 重复 50、100 或 250 次；
7. 在同一个 kNN graph 上计算相同指标。

这个 null 同时匹配 group size 和大致空间区域，减少“群体位于胚胎稠密/稀疏区域”造成的直接偏差。随机数种子固定，因此相同数据、group 和参数会得到相同结果。

每个指标输出：

```text
null_mean
null_sd
z_score = (observed - null_mean) / null_sd
percentile = (1 + count(null <= observed)) / (N_null + 1)
```

Purity/LCC 的正 z 表示高于 null；Normalized Rg 的负 z 表示比 null 更紧凑。Anisotropy 的正负只表示方向，不代表“好/坏”。

重要限制：当前 null 是逐时间的局部控制，不保持一组随机 lineage 跨时间的 identity，也不匹配 division history、fate composition 或 initial Rg。因此它适合探索性 effect-size/context，不应把 percentile 当作经过校正的正式 p-value。

## 7. 最低 group size

界面采用 `minimum group size = 4` 作为解释提示：

- 少于 4 个 group cells 时仍计算并导出，便于查看 lineage 刚出现的阶段；
- CSV 中 `minimum_n_pass=false`；
- shape 在两个点就有 covariance，但低 n 极不稳定；
- 单细胞 LCC 定义为 1，只是数学边界，不代表已经形成连通群体。

## 8. 可视化和跨胚胎汇总

### 当前时间 summary

对 current playback time 上所有选中 embryo 的 metric 取 median、25% 和 75% quantile。`n` 是该时刻有有效数值的 embryo 数量。

### 时间 small multiples

每项 metric 独立 y 轴，使用相同 x 时间：

- 实线：embryo 间 median；
- 色带：embryo 间 IQR；
- 红线：当前 playback time；
- 点击图：跳转到最近的真实 data frame。

小多图避免把量纲不同的 Purity、LCC、Rg、Anisotropy 强行叠在同一 y 轴上，同时保持时间对齐。

### Embryo comparison table

- `Now`：逐 embryo 的当前 time/frame 值；
- `Across time`：每个 embryo 在 group 实际出现时间内的 metric median；
- 表格底色只编码当前 embryo list 内的相对排序，不表示显著性。

### Descriptive readout

程序查看每个 embryo 的跨时间 median z，若至少 60% embryo 同方向超过约 1 SD，就显示一句描述。它只是帮助发现值得回到 3D 查看或后续建模的问题，不是自动生物结论。

## 9. CSV 字段

固定字段：

```text
dataset, group, group_source, group_root,
embryo_id, embryo_label, time/frame/generation,
group_size, total_cells, minimum_n_pass, k, null_samples
```

每个被勾选 metric 有：

```text
<metric>_value
<metric>_null_mean
<metric>_null_sd
<metric>_z_score
<metric>_percentile
```

Shape 另有 `shape_lambda_1/2/3`。未勾选的指标不会计算，也不会出现在 CSV；group 尚未出现的 frame 保留空 metric 值和 `group_size=0`。

## 10. 推荐的第一轮分析

1. 选择少量已经注册的 embryo；
2. 分别保存 `ABpl descendants`、`MS descendants`、`C descendants`；
3. 固定 `k=6`、null=100，四项指标全部运行；
4. 先看时间曲线是否在多个 embryo 同步变化，再看 individual embryo table；
5. 点击变化区间回到 3D，确认变化不是 missing cells、时间覆盖不同或坐标异常；
6. 用 k=4/8/10 重跑，检查结论是否只依赖单个邻域尺度；
7. 导出 CSV，在 Python 中进一步画 individual trajectories、mixed-effects model 或更严格 null。

只有在这一层显示可重复的时空模式后，才适合继续做 persistent cohesion、velocity correlation、bilateral lineage symmetry 和“symmetry 原因”的逐步检验。
